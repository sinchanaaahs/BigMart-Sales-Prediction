# BigMart Sales Prediction

A machine learning project for predicting BigMart product sales using XGBoost Regression.

## Project Overview

This project uses machine learning techniques to predict product sales based on the features available in the BigMart sales dataset.

## Objective

- Analyze the BigMart sales data
- Preprocess the available features
- Build a regression model
- Predict product sales
- Evaluate model performance

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost

## Machine Learning Model

### XGBoost Regressor

The project uses an XGBoost Regression model to predict product sales.

## Workflow

1. Data preprocessing
2. Feature preparation
3. Model training
4. Sales prediction
5. Model evaluation

## Results

The model achieved an R² score of approximately **0.88–0.90** on the evaluated data.
